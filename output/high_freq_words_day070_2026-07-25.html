#691
swing /swɪŋ/
Lv.1 v./n. 摇摆；秋千；挥舞
例句 Example
Children like to swing on the swings.
孩子们喜欢荡秋千。
#692
switch /swɪtʃ/
Lv.1 v./n. 切换；开关；转换
例句 Example
Please switch off the TV.
请关掉电视。
#693
system /ˈsɪstəm/
Lv.1 n. 系统；制度；体系
例句 Example
This computer system is new.
这个电脑系统是新的。
#694
table /ˈteɪbl/
Lv.1 n. 桌子；表格；目录
例句 Example
Please set the table.
请摆好餐桌。
#695
take /teɪk/
Lv.1 v. 拿；取；花费；乘坐
例句 Example
Take this medicine twice a day.
每天吃两次这个药。
#696
take care /teɪk keər/
Lv.1 phrase 保重；小心
例句 Example
Take care of yourself.
照顾好自己。
#697
talk /tɔːk/
Lv.1 v./n. 说话；谈话；演讲
例句 Example
Let's talk about this.
我们来谈谈这个吧。
#698
task /tɑːsk/
Lv.1 n. 任务；工作；作业
例句 Example
This is an easy task.
这是一项简单的任务。
#699
taste /teɪst/
Lv.1 v./n. 尝起来；味道；品味
例句 Example
This food tastes good.
这食物味道很好。
#700
teacher /ˈtiːtʃər/
Lv.1 n. 教师；老师
例句 Example
My teacher is very kind.
我的老师很和蔼。
